# Saffron & Stone — React Cafe Website

A responsive fictional cafe website built with React + Vite.

## Requirements
- Node.js 18 or newer
- npm (included with Node.js)

## Run locally
1. Extract the ZIP folder.
2. Open the folder in VS Code.
3. Open the VS Code terminal: **Terminal → New Terminal**.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed in the terminal (usually http://localhost:5173).

## Create a production build

```bash
npm run build
```

## Customize before using in a Fiverr portfolio
- Replace the fictional cafe name, address, phone number and social handle.
- Replace menu items and prices with your chosen demo content.
- Replace the Unsplash image URLs if you want different photography.
- The reservation form is front-end demo behavior only. It does not send email or store bookings. Connect a backend or booking provider for real reservations.

## Included features
- Responsive navigation with mobile menu
- Hero section and calls to action
- Cafe story and photo gallery
- Menu category filters
- Reservation request form with confirmation message
- Contact details and opening hours

All business details are fictional and intended for portfolio demonstration.
